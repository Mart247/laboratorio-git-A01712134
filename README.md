## Reflexión
¿Qué parte de la práctica te resultó más confusa y cómo la resolviste?

La parte más confusa fue la resolución del conflicto al editar el nombre del proyecto, ya que en un inicio no se generaba correctamente el conflicto o el editor no me permitía seleccionar y conservar ambas versiones. Lo resolví revisando con detenimiento las marcas de conflicto, editando el archivo manualmente en VS Code para combinar las propuestas de texto sin dejar marcas residuales, y asegurándome de guardar y hacer el commit para completar la integración.

¿Cómo crees que tu equipo usará el repositorio durante las etapas de UX y UI?

El equipo usará el repositorio para centralizar la documentación de diseño y prototipado de forma organizada. Utilizaremos las carpetas docs/ux y docs/ui para subir avances, investigaciones de usuario, enlaces a tableros de Figma y exportaciones de pantallas, manteniendo un control de versiones claro para que todos trabajemos sobre la misma línea de avance antes de empezar la etapa de desarrollo.
